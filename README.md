# callout-colors

A Claude Code mod: colors "decision for you" and summary sections in
assistant replies so they stand out in long sessions.

## What it does

- Decision sections (`Decision for you`, `Decision needed`, `Needs your
  input`, `Your call`): bordered box, text in the theme's `warning` color.
- Summary sections (`Summary`, `TL;DR`, `Recap`): same, `suggestion` color.
- The engine's between-tool-call summaries: whole block colored as summary.

A section opens on a heading, bold label or plain label matching the above
and runs to the next heading / bold label or the end of the reply. Labels
inside code fences are ignored. Text before the first callout keeps the
engine's own drawing; callout text is drawn plain (bold and `#` stripped).

Works best when the agent labels sections consistently, e.g. in
`~/.claude/CLAUDE.md`:

```md
Always label sections `**Decision for you:**` (last in reply) and `**Summary:**`.
```

## Install

```bash
git clone https://github.com/Tyru5/claude-callout-colors ~/claude-code-mods/callout-colors
claude --plugin-dir ~/claude-code-mods/callout-colors
```

Or set it permanently in `~/.claude/settings.json` (`:`-separated for several):

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "/path/to/claude-callout-colors" } }
```

## Develop

```bash
claude plugin test .
```

`.claude-plugin/types/` is generated by the engine on load and ignored.

## Layout

- `hooks/register.tsx`: `ui.render` hook on `AssistantMessage`.
- `hooks/split.ts`: callout detection; label patterns at the top.
- `hooks/*.test.ts`: suite run by `claude plugin test`.
